#  教务管理系统 (Campus Management System)

一个基于 Java 纯手写的控制台版教务管理系统，主要用于练习面向对象编程、集合框架、异常处理及 Git 版本控制。

##  技术栈
*   **语言**：Java (JDK 26)
*   **核心机制**：面向对象（封装、继承、多态）、ArrayList 集合、HashMap、异常处理（try-catch）、Scanner 控制台交互。
*   **架构设计**：采用 `Model - Service - App` 三层架构，实现数据、业务与界面的解耦。

##  核心功能
*   [x] **学生模块**：支持添加学生、按学号查找、按学号删除。
*   [x] **教师模块**：支持添加教师、按工号查找、按工号删除。
*   [x] **安全验证**：执行敏感操作（增删）前需输入密码进行权限校验。
*   [x] **防崩溃机制**：完善的输入异常捕获，用户输入字母、标点或空值时程序不会崩溃，而是给出友好提示。
*   [ ] **待开发**：学生/教师信息修改功能、数据本地持久化（Save/Load）、基于角色的权限分离（管理员/普通用户）。
